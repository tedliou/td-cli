# 第三方授權與聲明

td-cli 自有程式碼採 [MIT](LICENSE)。下列元件維持各自授權，並未改授 MIT。
完整原文、著作權及 NOTICE 保存於 `LICENSES/`；機器可讀的版本、來源、SHA-256
與原文對照見 [inventory.json](LICENSES/inventory.json)。

## 範圍與原始碼

此清單是 `uv.lock` 工具鏈、setuptools 內嵌元件、pydantic-core wheel 所附 Rust SBOM
（含跨平台及建置元件）的聲明聯集，不表示每個 ZIP 都執行所有元件。
四個 ZIP 附相同文件，Agent Component 不因此內含 Python 執行環境。
套件原文取自對應已安裝 wheel；Rust 原文取自 SBOM SHA-256 驗證過的 crates.io 原始碼封裝。
`wit-bindgen-rt` 的 crate 未附授權檔，因此採同版上游倉庫的 Apache-2.0 選項。

`bidict`、`certifi` 及其他 MPL 元件保持未修改，其原始碼依 MPL 提供。
下表的「來源／原始碼」連結指向對應精確版本的原始碼封裝或上游版本頁，
可免費取得；td-cli 的 MIT 條款不限制使用者在 MPL 下的權利。
日後若修改此類元件，必須另外提供修改後的對應原始碼並更新此聲明。

PyInstaller 使用其 bootloader／產物散布例外；原始 COPYING 仍保留。
CPython 的歷史授權及原生元件聲明另列於 runtime 項目；Microsoft runtime
的條件見 CPython LICENSE。Python 原生版本快照記錄於 inventory 的 `runtime_variants`，打包前須核對。
已核對的環境為官方 Windows Python 3.11.9（既有 CI）與 uv Python 3.11.15（本機）；
兩者的 Python LICENSE 與原生版本均明確比對，其他環境須先重新審查。
TouchDesigner 本體與 Derivative 內建元件不隨本專案散布，仍受
[Derivative 授權](https://derivative.ca/UserGuide/Licensing) 規範。
