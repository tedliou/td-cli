## Command acceptance

- `ops.rename` returned verified old/new names and canonical paths.
- Exact `ops.disconnect` removed only the requested endpoint.
- `ops.connect --replace` atomically replaced the occupied input and returned
  the previous source path/output index; the ordinary connect result retained
  nullable `previous_connection`.
- `parameters.list` returned 25 real `constantTOP` descriptors with internal
  names, labels, pages, styles, builtin/custom/hidden/read-only flags, modes,
  conservative value kinds, expression capability/source, and menu metadata.
  Multi-OP, Sequence, Python, and unknown values do not advertise JSON set or
  expression support.

Two locked-runtime defects were found by live repetition and fixed. SocketIO
DAT cannot serialize nested Python `None`, so the internal Agent transport
omits nullable dictionary fields and uses a private null-list sentinel; the
Daemon restores the public nullable result contract. Some Menu parameters
return `menuNames` and `menuLabels` as `None`, now normalized to empty arrays.
The final live run confirmed public null fields, menu arrays, and Agent 0.1.1.

The SocketIO calls follow Derivative's documented `emit(event, data=dict)` API:
<https://docs.derivative.ca/SocketioDAT_Class> and
<https://docs.derivative.ca/SocketIO_DAT>.
