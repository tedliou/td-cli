## 離線升級、同版與冷開

`td-agent upgrade-project` 的正式前置條件是機器上沒有任何 TouchDesigner 程序。第一次嘗試時作者的作品 TD 還開著，兩次呼叫都依設計在修改前失敗（`close all TouchDesigner processes before offline upgrade`），來源檔沒有變。後來由主代理協調時段：作者的作品 TD 在沒有未保存修改的狀態下正常關閉，確認全機 TD 程序為 0 後才執行，完成後作品 TD 立即重新開啟。作品檔與 Daemon 都未觸碰。

命令在 `E:\td-cli` 下執行，每次總期限 90 秒。先以當下 SHA-256 執行一次，再以升級後的 SHA-256 執行同一命令一次：

```powershell
uv run td-agent upgrade-project .codex\release080\src070.toe --artifact .codex\release080\candidate\td-agent.tox --manifest .codex\release080\candidate\td-agent.tox.manifest.json --tools-dir "C:\Program Files\Derivative\TouchDesigner\bin" --expected-sha256 <當下 SHA-256> --timeout 90
```

`src071.toe` 使用同一命令。
