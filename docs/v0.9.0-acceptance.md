## 離線升級、同版與冷開（尚未執行）

`td-agent upgrade-project` 的正式前置條件是機器上沒有任何 TouchDesigner 程序。作者的作品 TD（PID 2780）目前開著，依規定不能關閉，所以 0.8.0 → 0.9.0 升級、同版再執行與冷開都尚未執行。需要由主代理協調一段時間：作者的作品 TD 在沒有未保存修改的狀態下正常關閉，確認全機 TD 程序為 0 之後，執行以下命令：

```powershell
uv run td-agent upgrade-project .codex\release090\src080.toe --artifact .codex\release090\candidate\td-agent.tox --manifest .codex\release090\candidate\td-agent.tox.manifest.json --tools-dir "C:\Program Files\Derivative\TouchDesigner\bin" --expected-sha256 <當下 SHA-256> --timeout 90
```

完成後以升級後的 SHA-256 再執行一次（預期 `unchanged`），再冷開驗證。作品本身不需要這一步：作品內嵌的 0.8.0 Agent 已能執行 38 項 menu。
