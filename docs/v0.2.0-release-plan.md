# v0.2.0 Release plan

## Version decision

The post-v0.1.2 capability set ships together as v0.2.0. It adds 18 public
Commands across graph structure, Operator state, DAT content, Parameters,
COMP hierarchy wiring, family inspection, and Trusted TOX Import. Protocol v1
remains compatible and no existing public Command is deliberately removed or
weakened, but the breadth is too large for an honest patch increment.

All executable tools and the Agent Component form one Release. Mixing versions
would break capability advertisement and typed Command agreement, so none of
the seven increments is released independently. Published v0.1.2 assets and
tags remain immutable.

## Release gates

- Version sources agree on `0.2.0`: package metadata, Agent manifest, three
  executable `--version` outputs, filenames, installer metadata, and tests.
- Protocol stays at version 1 and all v0.1.2 Commands and security/lifecycle
  invariants remain covered by the complete regression suite.
- TouchDesigner 2025.32050 rebuilds the Agent from the exact final source
  commit and produces an immutable staged artifact.
- PyInstaller builds all three executable tools; packaging produces four
  archives and `SHA256SUMS`; packaged tools pass clean-directory and live
  Online Instance smoke.
- Promotion to `main`, protected release-environment approval, immutable tag
  creation, remote asset digest verification, publication, and installed
  upgrade/reinstall/uninstall acceptance remain mandatory.

The release workflow accepts strict pre-1.0 SemVer versions rather than a
hard-coded v0.1.0-v0.1.2 list. Its exact-main, immutable-tag, draft-first,
staged-Agent, environment-approval, and digest gates are unchanged.
