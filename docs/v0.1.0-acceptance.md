# Prototype v0.1.0 acceptance

Date: 2026-08-09

Platform: Windows 11, Python 3.11, TouchDesigner 2025.32050

Release Version: `0.1.0`; Protocol Version: 1

This record consolidates the ten acceptance conditions that originated the
Wayfinder map. Local evidence uses only the public `td` interface for product
operations. The retained diagnostic bridge is used only to build, independently
inspect, introduce a bounded timeout test delay, and clean disposable probes. It
remains loopback-only, bearer-token authenticated, unsandboxed, and excluded
from Release Artifacts.

## Ten acceptance conditions

1. **Two simultaneous TouchDesigner Instances are listed.** A temporary copy
   of the acceptance project was launched in a second TouchDesigner process.
   Both were simultaneously Online as Instance IDs `2110dd68-...` (Selector
   `2110`) and `37c409b1-...` (Selector `37c4`).

2. **A Selector modifies only its selected Instance.** The same
   `/project1/tdcli_route_probe` existed in both Instances. Public CLI writes
   and reads returned `colorr=0.2` for `2110` and `colorr=0.8` for `37c4`.
   Omitting the Selector returned `instance_selector_ambiguous`, exit 4.

3. **Agents recover registration after a Daemon restart.** An orderly
   `td-daemon stop` / `start` retained Instance ID `2110dd68-...`, cleared
   draining only on a new socket open, and changed Connection ID from
   `55ea039e-...` to `76bd5084-...` without rebuilding the Agent Component.
   The same recovery passed again after enabling the locked-build gate.

4. **A closed Instance becomes Offline and is cleaned.** The second process was
   stopped by exact PID. It immediately remained visible as Offline with
   `offline_expires_at=2026-08-09T10:12:51.269Z`, then disappeared after the
   30-second retention while the first Instance remained Online.

5. **A repeated mutating Request executes once.** Two identical
   `ops.create` submissions used Request ID
   `019fe601-33c7-7973-918a-9c7b72c4f63b`; both returned the same succeeded
   snapshot, and an independent count found exactly one created Operator.

6. **Different Instances can operate concurrently; one Instance remains
   FIFO.** Two concurrent public CLI jobs wrote the two Instances successfully.
   On `2110`, queued `parameters.set` Requests ending `...68a092` then
   `...0143f` completed in submission order; final readback was the second
   value, `0.5`. The real Socket.IO integration suite also locks one in-flight
   Request per Instance and the 32-Request bound.

7. **A timed-out Request remains queryable.** A development harness delayed one
   Agent operation by 350 ms. `td --timeout 0.1` returned `wait_timeout`, exit
   6, and Request ID `019fe601-b19f-73b4-8db9-0f13e9fb500f` while dispatched.
   `td requests wait` later returned the same Request as succeeded. The delay
   was then removed and is not product code.

8. **Incompatible Protocol or TouchDesigner build is rejected explicitly.**
   Registration negotiates Protocol v1 and now requires exact build
   `2025.32050`. Real Socket.IO integration sends `2025.99999`, receives
   `protocol_incompatible`, and is disconnected. The locked live Agent then
   registered successfully after a Daemon restart.

9. **Primary Commands have stable JSON and exit codes.** Strict Protocol and
   CLI tests cover every public Command, JSON parser failures, terminal typed
   errors, and exits 0/2/3/4/5/6. Local validation passed 105 tests, Ruff
   formatting and lint, mypy, compileall, lock and diff checks. All three
   PyInstaller executables passed clean-directory version smoke:
   `td 0.1.0 (protocol 1)`, `0.1.0`, and `0.1.0`.

10. **Codex can create, connect, configure, and inspect a basic network only
    through `td`.** Public CLI created a `constantTOP` and `nullTOP`, wrote and
    read `colorr=0.25`, connected output 0 to input 0, and listed the source.
    The connect result returned both canonical paths and connector indices.
    Repeating the connection rejected typed `connector_occupied`, exit 5,
    rather than silently replacing the input. Independent inspection confirmed
    the connection before disposable Operators were removed.

## Added bounded mutation contract

`ops.create` is restricted to `constantTOP`, `noiseTOP`, `levelTOP`, and
`nullTOP`; names use a bounded safe grammar and collision is an error.
`ops.connect` accepts connector indices 0 through 255, requires the same
Operator family, validates both indices, and rejects occupied inputs. The
Commands are excluded from `batch.execute` so the existing all-items-before-
mutation preflight guarantee remains truthful.

Stable typed failures added for this contract are `operator_parent_invalid`,
`operator_already_exists`, `operator_create_failed`,
`operator_family_mismatch`, `connector_not_found`, `connector_occupied`, and
`connector_connect_failed`. Unknown future errors still produce
`protocol_incompatible`.

## Remaining publication gates

This acceptance permits a human-reviewed promotion candidate; it is not yet a
public Release. Publication still requires the human `develop` and `main` merge
gates, repository rulesets and protected release environment, a dedicated
least-privilege GitHub App, an authorized TouchDesigner staging runner, exact
main-commit Agent Component staging, successful GitHub validation, verified
draft assets, immutable `v0.1.0`, and Bootstrap Installer lifecycle acceptance.
