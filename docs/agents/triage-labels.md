# Triage Labels

工程技能使用五種標準 triage 角色；下表將其對應到本 repo 實際使用的標籤。

| 標準角色 | 本 repo 標籤 | 意義 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 維護者需評估此 issue |
| `needs-info` | `needs-info` | 等待回報者補充資訊 |
| `ready-for-agent` | `ready-for-agent` | 規格完整，可交由 AFK agent 處理 |
| `ready-for-human` | `ready-for-human` | 需要人工實作 |
| `wontfix` | `wontfix` | 不會處理 |

技能提及任一標準角色時，請套用表中對應的標籤。
