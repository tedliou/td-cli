# 0.11.0 驗收與發布狀態

日期：2026-10-24。

## 範圍

- PR #178：CLI 可用性修正（選項說明、commands schema、digest 大小寫、MSYS 提示、PowerShell 5.1 installer）。
- PR #180：Agent 讀取介面與大型結構操作（#176、#171、#170、#166、#167、#168、#164、#153、#169、#159），驗收見 [agent-read-surface-acceptance.md](agent-read-surface-acceptance.md)。新增 capability 與選項，舊 Agent 收到新選項時由 Daemon 以 `command_unsupported` 拒絕，所以升 minor。
- PR #179（#163）：`td` 改用 onedir 打包，CLI 不再載入 Daemon 伺服器套件，驗收見 [cli-startup-acceptance.md](cli-startup-acceptance.md)。
- `td-agent upgrade-project` 白名單新增精確 canonical 0.10.0 Agent。
  - 兩份內嵌 hash 取自已安裝的官方 0.10.0 `td-agent.tox`（SHA-256 `02fbc76dad3d827e89d979daeaa371e2dfe988f66217b31750bbb97fa15fdc19`，與其 release manifest 相符）：以 `VendorTools.expand` 展開後，由 `script_hashes` 算出。這份 artifact 就是 v0.10.0 Release 的 `td-agent-component-v0.10.0-td2025.32050.zip` 內容，可從該 Release 重現。
  - 同一方法套用在官方 0.9.0 artifact 上，得到的 hash 與既有 `V090_HASHES` 完全相同。
  - 0.10.0 的 `socket_callbacks`、`heartbeat_execute`、`operator_catalog` 與 0.6.0 起的 hash 相同，只有 `agent_extension` 與 `agent_manifest` 不同。
- `uv.lock` 只有本專案版本字串改變，`LICENSES/inventory.json` 只更新 `lock_sha256`；`scripts/check_licenses.py` 驗證 272 份授權文件。

## 隔離 locked 驗收（candidate）

Disposable project 沿用 0.9.0 的作法：官方 Samples `NewProject.toe` 加 Execute DAT，`toecollapse` exit 0。啟動時 `LOCALAPPDATA` 指向 scratch，Agent 找不到 `auth.token`，停在 `waiting_for_daemon`。使用者的 Daemon 全程未觸碰；每一步結束時機器上都沒有 TouchDesigner 程序。

- [build.json](evidence/v0110/build.json)：PID 26684 以 `agent/build_td.py` 從 release commit `04ab5c6` 的 source 建置 candidate（revision `2e100fa3164903854fb07da3ed5f68114cf5d27f0017a8de01289571951e07dc`），SHA-256 `77c5d55b70d01ad0397d0bb3897d3e4227c24c33a06cffa048747d7a396723d1`。`td_cli.agent_tool inspect-artifact` 回報 valid。
- [verification.json](evidence/v0110/verification.json)：PID 22852 以 `loadTox` 載入 candidate。Agent 為 0.11.0，capabilities 含 `parameters.menu.set` 與 `project.snapshot:options`，socket 未啟用。3 項 menu 以 `preserve=index` 改名後，TD 讀回一致，`validated=true`。
- [read-surface-candidate.json](evidence/v0110/read-surface-candidate.json)：以 `tools/locked_agent_read_surface_acceptance.py` 走真實 Daemon transport（隔離 port 19982）與 SocketIO DAT，在 release candidate 上重跑讀取介面驗收（TD PID 27460，exit 0，Daemon thread 正常停止）。共 63 個 Request；8 個失敗都是預期的拒絕，step 與錯誤碼和 PR #180 的驗收完全相同。

## 離線升級、同版與冷開

執行前確認全機沒有 TouchDesigner 程序。

1. [source-0.10.0.json](evidence/v0110/source-0.10.0.json)：PID 29572 載入官方 0.10.0 Agent（沒有 `project.snapshot:options`）與 sentinel Constant CHOP（42），存成 disposable `src0100.toe`，SHA-256 `17abfead349fd34e795722d491b70a54b031f0cfa58958c70806e44803e94836`。
2. [upgrade.json](evidence/v0110/upgrade.json)：

   ```powershell
   uv run td-agent upgrade-project .codex\release0110\src0100.toe --artifact .codex\release0110\candidate\td-agent.tox --manifest .codex\release0110\candidate\td-agent.tox.manifest.json --tools-dir "C:\Program Files\Derivative\TouchDesigner\bin" --expected-sha256 17abfead349fd34e795722d491b70a54b031f0cfa58958c70806e44803e94836 --timeout 90
   ```

   `status` 為 `upgraded`，Agent 0.11.0，留下備份，新的 SHA-256 為 `1da18f0e43f1b05cc7dc17ceb68cf79aa4b4042b482a953311bffa61cec366e2`。
3. [upgrade-rerun.json](evidence/v0110/upgrade-rerun.json)：以升級後的 SHA-256 再執行一次，`status` 為 `unchanged`，檔案 bytes 不變。
4. [cold-0.10.0.json](evidence/v0110/cold-0.10.0.json)：PID 30400 冷開升級後的專案。Agent 為 0.11.0，`Connectionstate` 為 `waiting_for_daemon`，socket 未啟用，capabilities 含 `project.snapshot:options`；sentinel 仍為 42；menu 改名後讀回一致，`validated=true`。
