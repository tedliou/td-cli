# v0.3.1 Release plan

## Version decision

The Protocol 2 outcome-delivery and windowless-Daemon correction ships as
`v0.3.1`. Published `v0.3.0` assets and tags remain immutable. This is a
pre-1.0 patch release because it preserves Protocol 2, the Request lifecycle,
and the public Command surface while correcting their shipped implementation.

All three executables and the Agent Component form one Release. Mixing Release
versions remains unsupported; installation and upgrade replace the complete
set together.

## Release gates

- Version sources agree on `0.3.1`: package metadata, lockfile, Agent manifest,
  executable version output, archive names, installer metadata, and tests.
- The full automated gate and independent Standards/Spec review for #97-#100
  remain green on the promoted commit.
- TouchDesigner 2025.32050 rebuilds the Agent artifact from the exact release
  source and repeats the corrected first-outcome, expected failure, mutation,
  retained-outcome replay, heartbeat, reinitialization, and performance probes.
- Frozen Windows executables pass clean-directory version smoke, and repeated
  Daemon start/status/stop produces no visible console window.
- The Agent stage binds the artifact bytes, locked-runtime verification, exact
  source commit, and Release Version before upload.
- Promotion to `main`, immutable tag creation, draft-first asset upload, remote
  digest verification, Latest selection, downloaded artifact smoke, and local
  installed upgrade acceptance are mandatory.

## Intentional limitations

- No Protocol alias, alternate outcome transport, or fallback scheduler is
  shipped.
- Authorized mutations are never retried automatically; uncertain execution
  remains `unknown` until the matching retained outcome refines it.
- TouchDesigner Power Off remains unsupported.
- Windows executables remain unsigned; published SHA-256 checksums establish
  integrity but do not bypass PowerShell, SmartScreen, or Defender policy.
